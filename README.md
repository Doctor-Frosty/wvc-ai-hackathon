# Second Look

**Check it before you trust it.**

An accessible web app that helps seniors spot, avoid and report scams. Paste a suspicious text, email, letter or call description and get a plain-language answer: whether it looks like a scam, why, and exactly what to do next. Practice mode ("Spot the Scam") builds the instinct to recognize scams before they happen.

## Track
**Senior Fraud and Scams**
with Successful Aging Solutions & Community Consulting (SASCC): How can we build helpful tools that support seniors' ability to detect, avoid, and report scams and fraud?
